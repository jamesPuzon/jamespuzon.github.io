Automatic Cat Feeder

Overview

This project focuses on building an automatic cat feeder that can reliably dispense food on schedule. It combines mechanical design, simple automation logic, and practical prototyping to create a dependable day-to-day feeding system.

Project Demo

Key Features

  • Automated food dispensing at set intervals
  • Integrated mechanical and electrical subsystem design
  • Prototype-focused build and iterative improvement process
  • Reliable operation for routine pet care use
